# Assets Folder

Hier kommen später die Game Assets:

## Struktur

- **sprites/** - Character sprites, tiles, backgrounds
- **audio/** - Music, sound effects, ambient sounds
- **fonts/** - TTF fonts für Text-Rendering
- **levels/** - Level-Definitionen (JSON oder custom format)

## Placeholder Status

Aktuell verwendet das Spiel primitive Shapes (Rechtecke) als Platzhalter.

In einer späteren Version werden hier echte Assets hinzugefügt:
- Echo Character Sprite (Pixel Art)
- Corrupted Versionen
- Glitch-Texturen
