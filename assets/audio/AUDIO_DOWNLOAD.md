## 📥 Schnell-Download (Alle auf einmal)

### FreeSound.org Collection
Alle Sounds sind von **FreeSound.org** (CC0 oder CC-BY Lizenz):

```bash
# Install youtube-dl oder yt-dlp für Batch-Download
# Oder manuell herunterladen:

1. Gehe zu https://freesound.org/
2. Erstelle ein kostenloses Account
3. Suche nach den Tags:
   - "8bit music"
   - "chiptune"
   - "horror ambient"
   - "jumpscare scream"
   - "retro jump sound"
```

### Alternative: OpenGameArt.org
- https://opengameart.org/content/512-sound-effects-8-bit-style
- https://opengameart.org/content/horror-sound-effects-library

### Alternative: Incompetech (royalty-free)
- Music: https://incompetech.com/
- Kategorien: "Unnerving", "Creepy", "Retro"

## 🛠️ Installation

1. Lade alle Audio-Dateien herunter
2. Platziere sie in diesem Ordner: `assets/audio/`
3. Benenne sie EXAKT wie oben angegeben
4. Rebuild das Projekt

```bash
assets/audio/
├── menu_music.mp3
├── level_music.mp3
├── corrupted_music.mp3
├── horror_ambient.mp3
├── jump.wav
├── collect.wav
├── death.wav
├── jumpscare.wav
├── whitenoise.wav
├── scare_appear.wav
└── scare_audio.wav
```
